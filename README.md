# Gerador de Senhas

Este programa tem o propósito de ser um gerador de senhas aleatórias simples

### Compilando

Compile o código para gerar um executável com:
```ps1
gcc main.c -o main
```
_Obs: Escolha um nome adequado ao invés de "main" após o "-o"_

### Como Funciona

Execute o programa com:
```ps1
./main
```
Após compilar o programa e executar o binário o usuário insere o 
número de caracteres que deseja para a senha, e o
programa devolve uma senha aleatória com essa quantidade desejada.
